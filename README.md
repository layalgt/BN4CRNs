The repository contains two python scripts:
(1) [BN_memory_robustness.py](BN_memory_robustness.py) simulates the 3-nodes boolean network and evaluates the prerequisites, memory and robustness. The output is saved in a separate CSV file inside a timestamped folder. The script contains detailed comments to guide readers.
(2) [Visualization.py](Visualization.py) generates the corresponding plots which are saved in the 'visualizations' folder.
